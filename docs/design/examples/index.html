Lista de verificación para revisión de PR

  • ¿Cada control tiene etiqueta visible además de placeholder?
  • ¿El borde del control usa --color-border-strong y no el --color-border decorativo?
  • ¿El mensaje de error está debajo del control y referenciado por aria-describedby?
  • ¿Los estados deshabilitado y de solo lectura tienen explicación textual visible?
  • ¿La obligatoriedad se lee sin depender del color?

✕Incorrecto
SRV-008431Barrido · Zona Norte08:00–10:00

Pruebe: el detalle tarda 900 ms y rebota, mientras un indicador late de forma continua junto a la lista.

El rebote y la duración larga hacen esperar en una tarea repetitiva, y el latido permanente compite con la lectura de datos.

Lista de verificación para revisión de PR

  • ¿La transición tiene origen y destino concretos, no solo un fundido?
  • ¿Las duraciones respetan 150 / 280 / 420 ms según el tipo de cambio?
  • ¿No hay animación en bucle ni entrada de página completa?
  • ¿Con prefers-reduced-motion el resultado sigue siendo evidente por color, borde, ícono y texto?
  • ¿La selección y el estado se conservan durante la transición?

Voz institucional en español

Cómo suenan las etiquetas, los errores y los estados vacíos bajo el registro formal aprobado.

DESIGN.md · Redacción UX en español

Mensaje de validaciónRegla: El error indica el problema y el próximo paso válido

✓Correcto
El horario deberá ser posterior a las 08:12, hora de la última actualización del servicio.

Registro formal, restricción explícita y una acción concreta que resuelve el problema en un paso.

✕Incorrecto
Error: ingresaste mal la fecha.

Mezcla voseo con el registro formal del producto, atribuye culpa, no indica la restricción y ofrece botones genéricos.

Lista de verificación para revisión de PR

  • ¿El registro formal se mantiene en etiquetas, ayudas, errores y confirmaciones?
  • ¿La acción se nombra con verbo y objeto específicos?
  • ¿Los términos de dominio coinciden con servicio, cuadrilla, asignación, recorrido y turno?
  • ¿El estado vacío distingue su causa y ofrece la próxima acción?
  • ¿La confirmación destructiva nombra el objeto afectado y su consecuencia?
