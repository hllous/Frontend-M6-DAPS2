# Contexto del backend M6

Esta carpeta contiene un espejo de referencia del contrato HTTP y del modelo de dominio del backend. Se copió desde `Backend-M6-DAPS2`, rama `develop`, commit `a05bc2e` (el merge de [#323](https://github.com/hllous/Backend-M6-DAPS2/pull/323)), el 20/10/2026 (la copia anterior citaba `30d55b0`, un commit previo al squash de [#313](https://github.com/hllous/Backend-M6-DAPS2/pull/313); antes, `d3b7b4a16c377d1a0f52915130803d1cb2433a22`, del 13/10/2026). Desde el 13/10 no hay rutas nuevas: [#289](https://github.com/hllous/Backend-M6-DAPS2/pull/289), [#290](https://github.com/hllous/Backend-M6-DAPS2/pull/290), [#315](https://github.com/hllous/Backend-M6-DAPS2/pull/315) y [#316](https://github.com/hllous/Backend-M6-DAPS2/pull/316) modifican rutas existentes. Ese snapshot documenta 134 rutas REST distribuidas en 23 tags de Swagger, la misma cuenta que el anterior.

**Qué cambió en el contrato documentado entre las dos copias:** `GET /services` suma los filtros `targetType` y `targetId`; `GET /tree-interventions` suma `treeId`; los expedientes ambientales devuelven `assignedCrewId` (derivado de la inspección más reciente con servicio vigente); un expediente `FORWARDED`, `DISMISSED`, `NO_VIOLATION` o `CLOSED` se reabre a `UNDER_REVIEW` cuando M2 manda `REOPENED`; y `POST /events/inbox` ahora recibe el sobre del Core. Esto sale de la documentación del backend, no de una verificación contra el código: [`CONTRACTS.md`](../../CONTRACTS.md) y los ADR conservan sus propias fechas de verificación (01/10/2026).

**Qué cambió en esta copia (13/10 → 20/10):** `POST /services/:id/suspend` acepta `note` opcional y el servicio devuelve `statusNote` (se limpia en `resume` y `cancel`); `GET /environmental-inspections/:id/violation-notice` responde `200` con `null` si la inspección no tiene acta, y `404` solo si no existe; y `derivaciones.md` aclara `requestingModule`. `entidades/environmental-report.md` documenta ahora los expedientes `FORWARDED` que M2 reactiva o cierra (Backend #304 y #308) y el orden por `updatedAt`; el efecto en la UI está en [`CONTRACTS.md`](../../CONTRACTS.md) (ver [#630](https://github.com/hllous/Frontend-M6-DAPS2/issues/630)). Desde #313 el Backend partió `bloqueantes.md` en un tablero de lo abierto y fichas por módulo en `docs/integracion/`: esos documentos no se espejan, y los enlaces de las páginas copiadas que apuntan a `bloqueantes.md#...` o a `integracion/...` apuntan al [repositorio Backend](https://github.com/hllous/Backend-M6-DAPS2/tree/develop/docs/integracion) (ver [#632](https://github.com/hllous/Frontend-M6-DAPS2/issues/632)). **Qué cambió en la copia del 20/10 (`a05bc2e`, [#636](https://github.com/hllous/Frontend-M6-DAPS2/issues/636)):** `GET /tree-interventions` acepta `priority` y `GET /environmental-reports` acepta `from`/`to` (`YYYY-MM-DD`, filtra por `updatedAt`, pendiente de confirmar con el PO); el estado de `StreetClosureRequest` suma `EXPIRED` (el Backend vence por tiempo los cortes aprobados que M7 deja expirar; el frontend lo soporta desde [#635](https://github.com/hllous/Frontend-M6-DAPS2/pull/635)); `confirm-reschedule` avisa a M2 la nueva fecha; y `DER.md` suma `ticket_m2_state` y las columnas `approved_from`/`approved_to`.

## Fuente de verdad y actualización

El repositorio Backend es la fuente de verdad. Este espejo es de solo lectura: cuando cambie un contrato, actualizá el original en Backend y luego volvé a copiar las páginas correspondientes; no corrijas aquí una diferencia.

El artefacto OpenAPI versionado de este snapshot se encuentra disponible en [Backend `docs/api/openapi.json`](https://github.com/hllous/Backend-M6-DAPS2/blob/d3b7b4a16c377d1a0f52915130803d1cb2433a22/docs/api/openapi.json); este espejo no lo duplica.

El espejo cubre el dominio y la API que consume el frontend. No incluye `eventos/`, `bloqueantes.md`, el despliegue ni los acuerdos de integración backend-a-backend; por eso, algunos enlaces relativos heredados de las páginas copiadas pueden apuntar fuera de este espejo. Para las hipótesis y los flujos del frontend, consultá [`CONTRACTS.md`](../../CONTRACTS.md); para el estado general del proyecto, [`ROADMAP.md`](../../ROADMAP.md). Los bloqueantes completos están en el [repositorio Backend](https://github.com/hllous/Backend-M6-DAPS2/blob/develop/docs/bloqueantes.md).
